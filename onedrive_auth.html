Microsoft Entra ID Configuration

Before connecting, you need to register an application in the Microsoft Entra Admin Center (Azure Active Directory) of your organization to obtain credentials.

How to configure in Azure Portal:

  1. Sign in to the Microsoft Entra admin center.
  2. Go to Identity > Applications > App registrations > Click New registration.
  3. Set Supported account types to Accounts in any organizational directory (Any Microsoft Entra ID tenant - Multitenant).
  4. Under Redirect URI, select Single-page application (SPA) and paste the Redirect URI shown above.
  5. In the registered App overview, copy the Application (client) ID and paste it into the field above.
  6. Ensure you grant Files.Read or Files.ReadWrite permissions under API Permissions.
