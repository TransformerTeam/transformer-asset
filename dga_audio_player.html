ขั้นตอนที่ 1 : การเก็บตัวอย่างและการประมวลผลข้อมูล (Data Computation) 0:08 - 0:35
Sampling & Mathematical Computation

การเตรียมข้อมูลและคำนวณตัวแปรทางสถิติเพื่อกำจัดความคลาดเคลื่อนและเลือกใช้ตารางเกณฑ์ตัดสินได้อย่างถูกต้อง:

• สุ่มเก็บตัวอย่างน้ำมัน (Sampling): ดำเนินการตามรอบวาระการทดสอบปกติขององค์กร
• คำนวณอัตราส่วน O2/N2: เพื่อเลือกใช้ตารางเกณฑ์ตัดสินที่ถูกต้อง โดยแบ่งเป็นกรณี O2/N2 ≤ 0.2 (Sealed Tank / Low Oxygen) และ O2/N2 > 0.2 (Free Breathing / High Oxygen)
• คำนวณค่าการเปลี่ยนแปลงสัมบูรณ์ (Δ Delta): หาผลต่างความเข้มข้นก๊าซแต่ละตัวเทียบกับผลทดสอบครั้งก่อนหน้า (Δ = GasCurrent - GasPrevious)
• คำนวณอัตราการเกิดก๊าซสะสม (Multi-point Rate): คำนวณความชันด้วยวิธี Linear Regression จากผลทดสอบ 3 ถึง 6 จุดล่าสุด ในช่วงระยะเวลา 4 ถึง 24 เดือน (ไม่เกิน 2 ปี) เพื่อขจัดความคลาดเคลื่อนจากการสุ่มทดสอบของห้องปฏิบัติการ

Status Categorization & Operational Guardrails
DGA Status 1 (Unexceptional / Normal Condition):
• เกณฑ์: ระดับก๊าซทุกตัว < Table 1 และ ค่า Delta ทุกตัว < Table 3 และ อัตราการเกิดก๊าซทุกตัว < Table 4
• การดำเนินการ: หม้อแปลงอยู่ในสภาวะปกติ ปลอดภัย ให้เปิดใช้งานตามปกติและสุ่มเก็บตัวอย่างตามรอบวาระปกติขององค์กรต่อไป
DGA Status 2 (Possibly Suspicious / Intermediate Condition):
• เกณฑ์ (ก): ระดับก๊าซทุกตัวต่ำกว่า Table 1 แต่พบว่ามีค่า Delta > Table 3 หรือ Multi-point Rate > Table 4 (ต้องทำการสุ่มเก็บตัวอย่างยืนยันผลภายใน 1 เดือนก่อนกำหนด)
• เกณฑ์ (ข): มีระดับก๊าซตัวใดตัวหนึ่งอยู่ระหว่าง Table 1 ถึง Table 2 (Table 1 < Gas ≤ Table 2) และอัตราการเกิดก๊าซทุกตัว < Table 4
• การดำเนินการ: เพิ่มความถี่ในการสุ่มเก็บตัวอย่างน้ำมัน เฝ้าระวังแนวโน้มการสะสมตัวของก๊าซอย่างใกล้ชิด และปรึกษาผู้ผลิตหากจำเป็น
DGA Status 3 (Probably Suspicious / High or Active Fault):
• เกณฑ์: มีระดับก๊าซตัวใดตัวหนึ่ง > Table 2 หรือ มีอัตราการเกิดก๊าซสะสม (Multi-point Rate) > Table 4
• การดำเนินการ: ถือเป็นสภาวะเสี่ยงสูง ต้องเฝ้าระวังอย่างเข้มงวด (พิจารณาติดตั้งเครื่องวัดออนไลน์ Continuous Monitoring), ดำเนินการระบุประเภทความผิดปกติ (Fault Identification), ทดสอบทางไฟฟ้าเพิ่มเติม และปรึกษาผู้เชี่ยวชาญหรือผู้ผลิตเพื่อวางแผนมาตรการแก้ไข
ขั้นตอนที่ 4 : การระบุประเภทความผิดปกติ (Fault Identification Methods) 1:25 - 1:42
Diagnostic Tools for Active Gassing & Status 3

เมื่อหม้อแปลงตกอยู่ใน Status 3 หรือพบสภาวะการเกิดก๊าซต่อเนื่อง (Active Gassing) มาตรฐานแนะนำให้ใช้วิธีวิเคราะห์เฉพาะทาง:

• Duval Triangles (1, 4, 5) และ Duval Pentagons (1, 2): เป็นวิธีหลักที่มีความแม่นยำสูงในการระบุประเภทความผิดปกติ (เช่น Partial Discharge PD, Thermal Faults T1–T3, Discharges D1–D2, Carbonization of Paper)
• Rogers Ratios & Key Gases: ใช้ในการประเมินสัดส่วนก๊าซคู่เปรียบเทียบ (CH4/H2, C2H2/C2H4, C2H4/C2H6) เพื่อยืนยันลักษณะพลังงานความร้อนหรือการอาร์กไฟฟ้า
